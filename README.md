# Mehmet Aytuğ Yürük — Personal Website

Personal academic website for my work in computer vision, medical image
analysis, and reproducible deep learning.

**Live site:** [mehmetaytugyuruk.github.io](https://mehmetaytugyuruk.github.io)

## Overview

The site presents my research profile, publications, selected open-source
projects, education, and contact links. It is a lightweight static site hosted
with GitHub Pages.

## Structure

```text
pages/about/          Research interests and contact details
pages/publications/   Publications with code and model links
pages/projects/       Selected research and software projects
pages/education/      Education, certifications, and awards
```

## Development

No build step is required. Serve the repository root with any static HTTP
server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

Links to email, GitHub, Google Scholar, LinkedIn, X, and Hugging Face are
