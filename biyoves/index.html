BiyoVes

Prepare biometric and Turkish vesikalık photos on your computer.

GitHub code Dataset How to use

What BiyoVes does

BiyoVes aligns a portrait, replaces its background, and places it on a white canvas. Choose a 50 × 60 mm biometric or 45 × 60 mm vesikalık format. Photos are processed on your computer.

50 × 60 mmBiometric
45 × 60 mmVesikalık
300 DPIPrint resolution
LocalOn-device processing

How to use

Install BiyoVes and start its local app.

macOS / Linux

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python app.py

Windows PowerShell

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python app.py

Requires Python 3.10–3.13. Open http://127.0.0.1:7860 after starting the app. The first run downloads its models.
