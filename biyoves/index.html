LOCAL PHOTO PREPARATION

BiyoVes

Biometric and Turkish vesikalık portraits, prepared on your computer.

Turn an everyday portrait into a clean, consistently placed, white-background photo. BiyoVes combines facial geometry, soft background matting, and format-aware composition in one local workflow.

A practical portrait workflow

Preparing an ID photo means more than removing its background. The face must be detected, aligned, and placed at a suitable size for the chosen format. BiyoVes automates those steps, then leaves the final decision to you.

How BiyoVes works

A compact pipeline built around facial geometry and a soft foreground matte.

01

Find facial geometry

MediaPipe Face Landmarker estimates the eye line and facial landmarks used for roll correction and placement.

02

Separate the portrait

BiRefNet Lite creates a soft foreground matte so the original background can be replaced cleanly.

03

Compose the photo

BiyoVes places the visible head on a white canvas sized for the selected biometric or vesikalık format.

See the difference

Synthetic examples show how varied portraits are placed on a consistent white background.

Two format presets

Choose biometric or vesikalık dimensions. These are composition targets, not a guarantee of acceptance by an issuing authority.

A review aid, not an approval stamp

The Quality Gate suggests manual review when the smaller eye-openness score falls below 0.20 or when multiple faces are detected. If several faces are found, BiyoVes processes the largest one.

Photo requirements vary by issuing authority. BiyoVes helps with image preparation but does not guarantee that a photo will be accepted.

OPEN SOURCE · PYTHON

Run BiyoVes locally

Clone the repository, install the app, and open its local interface.

macOS / Linux

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python app.py

Windows PowerShell

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python app.py

Use Python 3.10–3.13. Then open http://127.0.0.1:7860. The first run downloads and verifies the models while online; later processing can run offline.
