BiyoVes

Prepare biometric and vesikalık photos on your computer.

Turn an everyday portrait into a clean, consistently placed, white-background biometric or vesikalık photo. BiyoVes handles the complete workflow locally on your computer.

GitHub code Output formats Dataset How to use

What BiyoVes does

BiyoVes aligns a portrait, replaces its background, and places it on the selected white biometric or vesikalık canvas. Each uploaded photo produces three PNG outputs, processed entirely on your computer.

50 × 60 mmBiometric
45 × 60 mmVesikalık
3Prepared PNG outputs
LocalOn-device processing
Review guidance. The workflow assumes one person per photo. Closed-eye and head-or-chin clipping checks remain advisory quality signals; there is no separate multiple-person rejection or face-selection workflow. These checks do not guarantee acceptance by an issuing authority.

Output formats

Choose the format before processing the photo. The visible head dimensions are composition targets for the selected canvas.

Format Canvas Visible head target
Biometric 50 × 60 mm 36 mm
Vesikalık 45 × 60 mm 32 mm

These are BiyoVes composition targets and do not guarantee acceptance by an issuing authority.

How to use

Clone the repository, install its dependencies, and start the local app.

macOS / Linux

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python app.py

Windows PowerShell

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python app.py

Requires Python 3.10–3.13. Open http://127.0.0.1:7860, choose Biometric or Vesikalık, upload one photo, and download the three PNG outputs. The first run downloads and verifies its models. A ready-to-run Windows installer is planned but is not available yet.
