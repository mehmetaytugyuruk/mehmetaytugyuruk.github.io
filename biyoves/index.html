BiyoVes

Prepare Turkish biometric and vesikalık photos on your computer.

Turn an everyday portrait into a clean, consistently placed, white-background photo. BiyoVes combines facial geometry, soft background matting, and format-aware composition in one local workflow.

GitHub code 🤗Dataset How to use

What BiyoVes does

BiyoVes aligns a portrait, replaces its background, and places it on a white canvas. Choose a 50 × 60 mm biometric or 45 × 60 mm vesikalık format. Photos are processed on your computer.

50 × 60 mmBiometric
45 × 60 mmVesikalık
300 DPIPrint resolution
LocalOn-device processing

Batch processing benchmark

BiyoVes processed 1,000 photos in 9 minutes 7 seconds. At an assumed expert preparation time of 2 minutes per photo, preparing the same 1,000 photos manually would take 2,000 minutes (33 hours 20 minutes).

How BiyoVes works

01

Align the face

Facial landmarks guide eye-line correction and placement.

02

Replace the background

Soft foreground matting separates the person from the original background.

03

Prepare the photo

The portrait is placed on a white canvas in the selected format.

How to use

Install BiyoVes and start its local app.

macOS / Linux

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python app.py

Windows PowerShell

git clone https://github.com/mehmetaytugyuruk/biyoves.git
cd biyoves
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
python app.py

Requires Python 3.10–3.13. Open http://127.0.0.1:7860 after starting the app. The first run downloads its models.
